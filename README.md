# Seminary Games

Review games and simulations for seminary. Open `index.html` (the landing page) on the classroom screen.

## Hosting on GitHub Pages
1. In this repository, open **Settings**, then **Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save
3. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

All links are relative, so the site works at that address, at a custom domain, or on Netlify.
Phone games save their live data in the same Firebase database as before.
